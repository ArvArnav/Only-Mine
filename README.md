# For My Lovee — By Arnav ♡ Anushka

Static HTML/CSS/JavaScript website.

## Open locally
Open `love.html` or `index.html` in Chrome. Keep `style.css` and `script.js` in the same folder.

## Vercel
Upload the contents of this folder (not the parent folder) to the root of a GitHub repository. Import the repository into Vercel, select Framework Preset **Other**, and deploy. No npm or build command is required.

## Features
7 story screens including 6 interactive chapters, 160 generated note variants, original synthesized instrumental melody, apology letter, floating particles, and local progress saving. Music begins only after user interaction.

No third-party copyrighted music is bundled. Google Fonts requires an internet connection; fallback fonts work offline.
